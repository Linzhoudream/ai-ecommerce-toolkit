# 审核标准框架（Audit Standards）

> 数字分身是主理人的"守门人"，它的本职就是把关。把关不是凭感觉，而是把这四维标准固化成可执行、可复用的规则，让每次收"货"都有同一把尺子。

## 一、四维审核标准总表

| 维度 | 核心标准 | 具体怎么判断 |
|------|----------|--------------|
| **出图** | 无 AI 硬伤 | 畸形、崩坏、手指六根、文字错乱、元素不对称——一律打回 |
| **出图** | 真实感 | "拿在手里拍的"实拍感，不要精致到像盗图；不要一眼假 |
| **出图** | 以主理人过目为准 | 发给他看，他不皱眉、不犹豫，说"行，发吧"，才扣下"确认"章 |
| **文案** | 大白话，不装 | 说人话，不堆术语、不端架子 |
| **文案** | 故事驱动，不是数据驱动 | 用场景和故事讲清楚，不要干巴巴列数字 |
| **文案** | 短句分段 | 受不了啰嗦，一段顶多三五行 |
| **文案** | 给 2–3 版让选 | 给选择题，不做填空题；"不太好"= 感觉不对味，不是质量差 |
| **交付** | 无硬伤 | 错字、畸形、水印、明显破损——一个都不能带出去 |
| **交付** | 像"认真做了" | 交出去的东西要让人感到你用心，不是敷衍糊弄 |
| **交付** | 做不到的不提前说 | 做不到的效果，预先讲清楚，不画饼、不虚报 |
| **验收** | 主理人拍板 | 最终是否放行，以主理人本人确认为准，分身不做终审 |
| **验收** | 留痕可查 | 每一版过了哪关、谁确认、何时确认，都要能回溯 |

## 二、三条优先级金句

1. **出图看硬伤和真实感，其余看主理人皱眉不皱眉。** 技术细节他不懂，也不该让他懂，他只看"感觉对不对"。
2. **文案宁短勿长，宁白勿装。** 短句是尊重主理人的时间预算。
3. **交付前一次自查，做到"交出去不脸红"。** 你自己都不觉得能拿出手的东西，别往外送。

## 三、一句话验收口径

> 所有产出，最终都过"主理人过目"这一关。分身可以盖章"建议通过"，但最后的"放行章"永远在主理人手里。
