# AI 视频提示词模板

> 使用说明：每次生成视频前，复制此模板填写对应要素。

---

## 一、提示词六要素

| 要素 | 说明 | 填写 |
|------|------|------|
| 1. 主体 | 画面的核心对象 | `[主体描述]` |
| 2. 动作 | 主体在做什么 | `[动作描述]` |
| 3. 场景 | 在什么环境中 | `[场景描述]` |
| 4. 光影 | 光线、色调、氛围 | `[光影描述]` |
| 5. 镜头 | 景别、运镜方式 | `[镜头描述]` |
| 6. 风格 | 画面风格/质感 | `[风格描述]` |

**组合示例**：
```
[主体]一只毛绒小熊，[动作]坐在窗台上被风吹动耳朵，[场景]阳光明媚的午后卧室窗台，
[光影]暖色调自然光，逆光带光晕，[镜头]特写镜头，缓慢推进，
[风格]电影质感，浅景深，治愈系
```

## 二、箱包类提示词模板

### 静态展示型
```
一款[款式描述]，[颜色材质]，放置在[场景]上，[光影]，[镜头：环绕运镜360度]，
[风格：商业广告质感，4K高清，背景虚化]
```

### 使用场景型
```
一位[人物描述]背着[产品名]，[动作：走在城市街道]，[场景描述]，
[光影：清晨自然光]，[镜头：跟随运镜，中景到近景切换]，[风格：生活化Vlog质感]
```

## 三、毛绒玩具类提示词模板

### 特写质感型
```
一只[产品描述]，[材质细节]，[动作]，[光影：柔光箱打光]，
[镜头：微距特写，缓慢推进]，[风格：治愈系暖调，浅景深，日系清新]
```

---

## 四、工具选择

| 工具 | 适用场景 | 优势 |
|------|----------|------|
| **即梦** | 静态产品展示 | 中文理解强、出图快 |
| **可灵** | 人物动态、运镜 | 动作流畅、运镜自然 |
| **Seedance** | 图生视频 | 参考图还原度高 |

### 通用建议
- 单条提示词控制在 80-150 字
- 先生成 3s 短片测试效果
- 运镜用动词：推进 / 平移 / 环绕 / 仰拍 / 俯拍 / 跟随
