# 发布前检查清单

> 使用说明：发布前逐项检查，全部打勾后再发布。

---

## 一、视频技术检查

- [ ] 分辨率达标（竖屏 1080x1920 / 横屏 1920x1080）
- [ ] 帧率合适（口播 30fps / 动态运镜 60fps）
- [ ] 画面比例正确（抖音小红书 9:16 / 视频号 6:7）
- [ ] 文件大小合理（60s 以内不超过 100MB）
- [ ] 画质清晰无压缩痕迹
- [ ] 画面无黑边、无裁切错误
- [ ] 导出格式为 MP4（H.264 编码）
- [ ] 音画同步，无延迟/错位

---

## 二、内容检查

- [ ] **前 3 秒钩子**：能在 3 秒内抓住注意力
- [ ] **字幕**：已添加字幕，无错别字，位置不遮挡画面
- [ ] **BGM 音量**：人声清晰不被盖过（BGM约20%-30%）
- [ ] **转场**：转场自然不突兀
- [ ] **节奏**：无冗长停顿，每镜头不超过 8 秒
- [ ] **结尾**：有明确引导（关注/点赞/评论/点击链接）
- [ ] **品牌露出**：产品/Logo 露出自然
- [ ] **敏感内容**：无违禁词、无敏感画面、无侵权素材

---

## 三、平台适配检查

### 文案
- [ ] 文案语言符合平台调性
- [ ] 文案长度符合平台限制
- [ ] 首行有吸引力

### 标签
- [ ] 标签数量合适（抖音 3-5 个 / 小红书 5-10 个）
- [ ] 包含品牌标签 + 流量标签 + 精准标签

### 商品/链接
- [ ] 商品链接已挂载
- [ ] 链接对应商品正确
- [ ] 封面图已设置

---

## 四、评论区准备

- [ ] **预设评论 1**（引导互动型）
- [ ] **预设评论 2**（补充信息型）
- [ ] **预设评论 3**（福利引导型）
- [ ] **置顶评论**已确定
- [ ] 安排发布后 30 分钟内开始回复评论

---

## 五、发布时间检查

- [ ] 选择流量高峰时段：
  - 早间：07:00-09:00
  - 午间：12:00-13:00
  - 晚间：18:00-20:00
  - 夜间：21:00-23:00
- [ ] 避开重大节日/热点事件抢流量
- [ ] 确认账号无限流/违规记录

---

## 六、发布后 24 小时追踪

### 0-1 小时
- [ ] 确认视频发布成功
- [ ] 发布置顶评论
- [ ] 回复前 20 条评论

### 1-6 小时
- [ ] 检查播放量趋势
- [ ] 持续回复评论

### 6-24 小时
- [ ] 记录核心数据：播放量 / 完播率 / 点赞数 / 评论数 / 转发数 / 商品点击
- [ ] 分析数据表现，记录优化点
- [ ] 决策：是否投流加热
