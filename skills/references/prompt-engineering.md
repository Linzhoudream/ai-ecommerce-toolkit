# AI视频提示词工程模板

> 本文档教你怎么写AI视频的「提示词」（prompt）。工具：即梦App / 可灵App（手机端）。

---

## 一、提示词六要素模型

```
[画质前缀] + [人物描述] + [场景环境] + [动作/剧情] + [镜头语言] + [风格/模型参数]
```

### 要素1：画质前缀
`4K` / `电影级画质` / `写实` / `高细节`

### 要素2：人物描述
`一位25岁短发年轻女性，穿米色风衣` / `一只橘色的英短猫`

### 要素3：场景环境
`在阳光明媚的客厅里，木质地板，窗外有绿植，自然光`

### 要素4：动作/剧情 ★最重要
`她拿起焦糖色托特包，拉开拉链，把笔记本电脑慢慢放进包里，然后单肩背起包转身走向门口`

### 要素5：镜头语言
`特写` / `全景` / `手持镜头` / `跟随镜头` / `一镜到底` / `俯拍`

### 要素6：风格/参数
`日系清新` / `暖色调` / `浅景深` / `竖屏9:16`

---

## 二、8条核心规律

1. **越具体，越准确** — AI不会读心
2. **动作要写出顺序** — 用「先...然后...接着...最后...」
3. **一句话一个动作** — 5秒视频=2-3个动作
4. **先画质后风格** — 顺序别乱
5. **用「否定」排除不要的** — 负面提示词
6. **一镜到底优先** — 降低穿帮风险
7. **竖屏要写明比例** — 加`竖屏9:16`
8. **一次生成2-3个版本** — 挑最好的

## 三、负面提示词模板

```
模糊，低画质，变形，多余的手指，扭曲的脸，文字，水印，logo，商标，塑料感
```

## 四、提示词模板速查卡

```
【画质】4K写实高清，
【人物】______（谁，长啥样，穿啥，或不写），
【场景】在______（地点+光线+背景），
【动作】______（先...然后...接着...，2-3个动作），
【镜头】______（特写/全景/手持POV/跟随/一镜到底），
【风格】______（日系/ins/暖色/冷色/浅景深/竖屏9:16）
【负面】模糊，变形，多余手指，文字，水印，塑料感
```

> 新手避坑：AI画面适合测款和引流，成交还是靠实拍图。
> 即梦vs可灵：即梦中文理解好、上手简单，可灵动作更流畅，新手先用即梦。
