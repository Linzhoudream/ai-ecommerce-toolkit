## 一、TikTok 跨境

### 发布时间
- 黄金时段：美东 21:00-01:00（对应北京次日 09:00-13:00）
- 白沟卖家在国内，建议北京时间 09:00-11:00 发

### 标签组合公式
1. 大流量词（1个）：#tiktokmademebuyit / #fyp
2. 品类词（1个）：#totebag / #catcarrier / #plushie
3. 场景/人群词（1-2个）：#commuter / #catlover / #giftideas
4. 转化词（0-1个）：#musthave / #tiktokshop

### 评论区运营
1. 置顶评论放链接
2. 前30分钟盯评论，有人问3分钟内回复
3. 回复带钩子：「Yes! Link in bio, 20% off today」

### 英文回复模板
- 问链接：`Link in bio! Free shipping over $XX`
- 问尺寸：`It's XXcm tall, fits a 15" laptop`
- 问价格：`Only $XX today, original $YY`

## 二、抖音

### 发布策略
- 三个黄金时段：07:00-09:00 / 12:00-14:00 / 18:00-22:00
- 最佳发车：提前30分钟发
- 频率：每天1-2条，间隔4小时以上

### 小黄车技巧
1. 视频后半段才提购物车
2. 商品标题改成场景化：如「能装15寸电脑的托特包｜通勤必备」
3. 配一张5-10元券，转化率翻倍

### DOU+ 投放决策表

| 视频发布2小时数据 | 动作 |
|-----------------|------|
| 播放<500，完播<20% | 别投，下一条优化 |
| 播放500-2000，完播30%+，有点赞 | 投50元试水 |
| 播放>2000，完播40%+，有评论 | 投100-200元加码 |
| 播放>1万，自然起飞 | 别投了 |

## 三、小红书

### 封面策略（决定80%点击率）
1. 主体清晰：产品占画面60%以上
2. 有文字：大字标题不超过8字
3. 高对比度：缩略图状态下也能看清

### 5个高点击标题公式
1. 「数字+痛点+解决」：`3个通勤党都在抢的托特包`
2. 「身份+真实体验」：`作为通勤3年打工人，这个包我锁死了`
3. 「反常识/争议」：`别买托特包了，除非你看完这篇`
4. 「场景+情绪」：`抱着它睡了一晚，治愈了我整个加班季`
5. 「问句」：`通勤包到底选双肩还是托特？`

### 测款玩法
1. 拍5个方向封面图，同一产品不同卖点
2. 5张图用不同标题发布，间隔1天1条
3. 观察48小时数据：点击率、收藏率、评论数
4. 数据最好的方向加码

### 测款判定标准（48小时）

| 指标 | 不及格 | 及格 | 优秀 |
|------|--------|------|------|
| 曝光 | <500 | 500-2000 | >2000 |
| 点击率 | <3% | 3-8% | >8% |
| 收藏率 | <2% | 2-5% | >5% |

## 四、视频号

### 核心逻辑
视频号靠社交推荐，适合做私域沉淀。

### 私域引导3步法
1. 视频里口播/字幕引导：「关注我，回复『包包』领通勤包选购清单」
2. 评论区引导加微信
3. 公众号联动承接

### 私域转化路径
```
视频号公域流量 → 关注/评论 → 视频号粉丝 → 引导加微信 → 微信私域 → 复购+转介绍
```

## 五、多平台分发注意事项

### 正确做法
1. **同素材不同剪辑（推荐）：** 拍一次素材，剪3个版本（抖音版/小红书版/视频号版）
2. **错峰发布：** 同一版本内容，平台间间隔48小时以上
3. **一素材多用：** 同一次拍摄，做成视频+图文+公众号文章

### 白沟箱包卖家的平台优先级
- **阶段1（0-1个月）：** 先做1个平台，国内抖音或跨境TikTok
- **阶段2（1-3个月）：** 扩展到2-3个平台
- **阶段3（3个月后）：** 全平台+私域

> 不要一上来4个平台全开，精力分散每个都做不好。
