# 产品类型策略路由

> 本文档告诉你「不同产品该怎么拍」。每种类型给出：推荐模式、核心卖点提炼方向、前3秒钩子参考、常见错误。

---

## 总览路由表

| 产品类型 | 首选模式 | 备选模式 | 核心逻辑 | 定价区间参考 |
|---------|---------|---------|---------|------------|
| 箱包（托特/双肩） | B 沉浸式 | C 评论区钓鱼 | 展示使用场景 | 150-300元 / $25-45 |
| 猫包/宠物包 | D 萌宠反应 | B 沉浸式 | 拍猫的反应 | 200-400元 / $30-60 |
| 毛绒玩具 | A 反差对比 | D 萌宠反应 | 情绪反差 | 50-150元 / $15-30 |
| 创意/新奇产品 | E 创意奇观 | A 反差对比 | 视觉冲击力 | 看产品 |

## 一、箱包类（托特包 / 双肩包）

### 推荐模式
- **首选：B 沉浸式第一视角** — 包的价值在于「用」，POV展示最有代入感
- **备选：C 评论区钓鱼** — 测自然流量
- **辅助：A 反差对比** — 旧包vs新包，强调收纳

### 核心卖点提炼方向

| 卖点方向 | 怎么体现 | 适合谁 |
|---------|---------|--------|
| 容量/能装 | 往包里塞很多东西 | 通勤党、学生 |
| 版型/挺括 | 装满东西也不塌 | 注重颜值 |
| 分区/收纳 | 每样东西有归位 | 整理控 |
| 材质/质感 | 拉链顺滑度、防水测试 | 品质党 |
| 百搭/场景 | 同一个包多场景 | 怕麻烦的人 |

**提炼口诀：** 别说「优质面料」，要说「下雨淋不湿」；别说「大容量」，要说「能装下15寸电脑+一整套换洗」。

### 前3秒钩子参考
1. 容量钩子：POV把购物筐的东西往包里塞，字幕「今天不用塑料袋了」
2. 痛点钩子：旧包拉链卡住塞不下
3. 争议钩子：男生背托特包走街上
4. 版型钩子：空包立桌上一掌推不倒
5. 场景钩子：早上出门前抓起包就走

### 常见错误
1. 铺一堆参数字幕 — 观众看不懂
2. 只拍静物不拍使用 — 没有代入感
3. 打光太像棚拍 — 一看就是广告
4. 前3秒放产品大特写+价格 — 立刻被划走
5. 标题堆砌卖点 — 没人看

## 二、猫包 / 宠物包

猫包的逻辑：**主角是猫，不是包**。

### 推荐模式
- **首选：D 萌宠反应** — 拍猫进包的反应
- **备选：B 沉浸式** — POV带猫出门
- **辅助：E 创意奇观** — 太空舱光影

### 核心卖点

| 卖点方向 | 怎么体现 | 说服谁 |
|---------|---------|--------|
| 猫愿意进去 | 猫主动钻进去 | 担心猫抗拒的主人 |
| 透气/看得见 | 透明罩+透气孔 | 担心猫憋坏的主人 |
| 安全/不逃 | 拉链+锁扣 | 怕猫半路跑了 |
| 好看/出片 | 背着上街像时尚单品 | 颜值党 |

### 常见错误
1. 当普通箱包拍 — 只展示包，没有猫
2. 硬塞猫 — 猫应激，评论区骂虐待
3. 只拍产品静物 — 猫包没猫没灵魂
4. 忽略「猫愿不愿意」这个核心卖点

## 三、毛绒玩具类

毛绒玩具卖的是「情绪价值」和「陪伴感」。

### 推荐模式
- **首选：A 反差对比** — 开箱前皱巴巴 → 拆开后治愈感
- **备选：D 萌宠反应** — 拍宠物或小孩反应
- **辅助：E 创意奇观** — 巨型尺寸冲击

### 核心卖点

| 卖点方向 | 怎么体现 |
|---------|---------|
| 触感/软糯 | 揉、抱、脸贴，特写毛的质感 |
| 尺寸/抱感 | 和人/宠物对比大小 |
| 颜值/表情 | 表情呆萌、丑萌 |
| 安全/不掉毛 | 揉搓不掉毛 |
| 解压/治愈 | 捏、抱、靠 |

**提炼口诀：** 不讲「PP棉填充」，要讲「抱一下班都不想上了」。

### 毛绒玩具的「黄金3镜头」
1. 触感特写：手指慢慢按进毛里，毛回弹
2. 抱感全景：人/宠物抱着毛绒，整团陷进去
3. 尺寸对比：和参照物对比大小

---

## 四、通用原则

### 卖点提炼的3个翻译
1. **参数 → 场景：** 「1680D牛津布」→「淋雨不湿」
2. **功能 → 痛点：** 「多分区设计」→「找钥匙不用翻整个包」
3. **形容词 → 画面：** 「超大容量」→「能装下15寸电脑+一整套换洗」

### 不同产品的「主角」分配

| 产品类型 | 视频主角 | 产品定位 |
|---------|---------|---------|
| 普通箱包 | 使用场景/人 | 融入生活的工具 |
| 猫包/宠物包 | 猫 | 猫的座驾 |
| 毛绒玩具 | 触感/情绪 | 治愈陪伴 |
| 创意新奇 | 新奇感 | 打破常规的体验 |

> 记住：观众不关心你的产品，关心的是「这跟我有什么关系」。
