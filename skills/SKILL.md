# 短视频生产流水线

> 通用型短视频制作技能，适用于任何产品类型、任何平台。
> 基于 MoneyPrinterTurbo/ViMax/OpenMontage 三大开源项目的流水线设计，全部替换为手机端/网页端工具。

## 何时激活

当用户提到以下任何关键词时激活本技能：
- "做视频"、"拍视频"、"视频脚本"、"短视频"
- "TikTok"、"抖音"、"小红书"、"视频号"
- "带货视频"、"种草视频"、"产品视频"
- "图生视频"、"AI视频"
- 产品名 + "视频"（如"托特包视频"、"毛绒玩具视频"）

## 核心原则

1. **拍反应，不拍台词** — 卖情绪，不卖产品
2. **前3秒定生死** — 每条视频必须设计视觉钩子
3. **越真实越容易爆** — 手机实拍优于精修AI画面
4. **一镜到底优先** — 降低制作门槛，提高产出频率
5. **数据驱动迭代** — 发够50条再谈"有没有天赋"

## 工作流程（7步）

### 第1步：产品诊断

向用户收集以下信息（可一次问完）：

```
1. 产品是什么？（如：焦糖色托特包、太空舱猫包、毛绒熊）
2. 核心卖点是什么？（最多3个）
3. 目标平台？（TikTok跨境 / 抖音 / 小红书 / 视频号 / 多平台）
4. 目标人群？（年龄、性别、使用场景）
5. 有实拍条件还是纯AI生成？（有产品实物 / 只有概念图）
6. 时长偏好？（15秒快节奏 / 30秒叙事 / 不确定）
```

### 第2步：模式选择

根据产品类型，从下方路由表选择1-2个视频模式，向用户推荐并说明理由。

**产品类型路由表：**

| 产品类型 | 首选模式 | 备选模式 | 核心逻辑 |
|---------|---------|---------|---------|
| 箱包（托特包/双肩包/猫包） | B 沉浸式 | C 评论区钓鱼 | 展示使用场景，让包"融入生活" |
| 宠物用品 | D 萌宠反应 | C 评论区钓鱼 | 拍宠物真实反应，不拍产品介绍 |
| 毛绒玩具 | A 反差对比 | D 萌宠反应 | 开箱前后的情绪反差 |
| 创意/新奇产品 | E 创意奇观 | A 反差对比 | 视觉冲击力优先 |
| 服饰/穿搭 | A 反差对比 | B 沉浸式 | 变装/场景切换 |
| 美食/食品 | B 沉浸式 | A 反差对比 | ASMR + 感官刺激 |

**视频模式库（详见 references/video-modes.md）：**

| 模式 | 名称 | 核心 | 完播率参考 | 转化率参考 |
|------|------|------|-----------|-----------|
| A | 反差对比 | Before/After 强对比 | 50-65% | 8-18% |
| B | 沉浸式第一视角 | 手持拍摄，真实代入 | 55-70% | 6-12% |
| C | 评论区钓鱼 | 不卖货，引发讨论 | 40-55% | 自然流量为主 |
| D | 萌宠/可爱反应 | 拍反应不拍产品 | 60-75% | 分享率高 |
| E | 创意奇观 | 视觉冲击/新奇感 | 45-60% | 分享率高 |

### 第3步：脚本/提示词生成

根据选择的模式，生成以下内容：

**模式A/B/E（有配音或字幕）：**
- 生成完整分镜脚本（参考 templates/script-template.md）
- 包含：时间轴、画面描述、字幕/台词、音效建议
- 前3秒钩子必须明确标注

**模式C/D（无配音，纯画面）：**
- 生成AI视频提示词（参考 templates/video-prompt-template.md）
- 一镜到底优先，降低制作门槛
- 包含：画面描述、镜头语言、氛围、负面提示词

**生成后必须做的事：**
1. 明确告诉用户用哪个工具生成（即梦/可灵/Seedance）
2. 给出视频比例（9:16竖屏 / 16:9横屏）
3. 给出时长建议

### 第4步：素材生产指导

根据用户条件给出具体操作指导：

**有产品实物：**
- 指导手机实拍角度、光线、背景
- 每条素材3-5秒，命名规范：镜号_内容_版本

**只有概念图/纯AI：**
- 指导用即梦/可灵App生成
- 提示词直接复制粘贴
- 同时生成2-3个版本供挑选

**工具矩阵：**

| 素材类型 | 首选工具 | 备选 | 费用 |
|---------|---------|------|------|
| AI视频 | 即梦App | 可灵App | 免费额度+付费 |
| AI图片 | 即梦/豆包 | 通义万相 | 免费 |
| 产品实拍 | 手机原相机 | 轻颜相机 | 免费 |
| 免费素材 | Pexels网页 | Pixabay | 免费 |
| 背景音乐 | 剪映曲库 | 抖音BGM | 免费 |

### 第5步：剪辑合成指导

给出剪映操作要点（简洁，不啰嗦）：

1. 按脚本顺序导入素材
2. 转场：叠化或闪白（0.3-0.5秒）
3. 字幕：白字+黑色描边，底部居中，单行显示
4. BGM：音量20-30%，不盖人声
5. 调色：适当提高对比度和饱和度
6. 导出：1080x1920，30fps

### 第6步：发布策略

**平台差异化（详见 references/platform-strategy.md）：**

| 平台 | 最佳时间 | 频率 | 特别技巧 |
|------|---------|------|---------|
| TikTok | 美东21:00-01:00 | 每天1-2条 | 英文文案+英文标签，评论区运营 |
| 抖音 | 7-9/12-14/18-22点 | 每天1-2条 | @小号，评论区置顶购买链接 |
| 小红书 | 12-14/20-22点 | 每天1条 | 封面决定点击率，标题要"问句" |
| 视频号 | 7-9/20-22点 | 每天1条 | 关联公众号，引导私域 |

**发布文案生成：**
- 根据平台生成3个文案版本供选择
- 生成对应标签（hashtags）
- 模式C：不挂商品链接，纯测自然流量

### 第7步：数据追踪与迭代

**告诉用户追踪什么（详见 references/data-iteration.md）：**

| 指标 | 健康标准 | 优秀标准 |
|------|---------|---------|
| 完播率 | >30% | >50% |
| 点赞率 | >5% | >10% |
| 评论率 | >1% | >3% |
| 转发率 | >0.5% | >2% |
| 转化率 | 看ROI | >5% |

**迭代规则：**
- 每发5条做一次小复盘
- 成功经验沉淀到提示词模板库
- 按"70%继承+30%创新"原则优化
- 数据差的视频不要删，分析为什么差

## 特殊场景

### 场景1：批量生产（给家人/朋友用）

当用户说"给我家人做个SOP"或"让朋友也能用"时：

1. 生成最小启动包（3个App + 1个提示词模板）
2. 输出一份不超过1页纸的操作SOP
3. SOP格式：早上5分钟脚本 → 上午20分钟素材 → 中午15分钟剪辑 → 下午发布

### 场景2：概念图测款

当用户说"测款"、"测试方向"时：
1. 生成5个方向的AI概念图提示词
2. 给出小红书测款发布策略
3. 提供数据观察标准和决策矩阵

### 场景3：跨境vs国内

当用户不确定做TikTok还是抖音时：
- TikTok：英文文案、英文标签、模式C/D优先、$25-45定价
- 抖音：中文文案、中文标签、模式A/B优先、150-300元定价
- 两个平台内容不能直接互发

## 用户背景

- 用户：林舟，白沟箱包电商卖家，无技术背景
- 设备：Win7电脑 + 安卓手机
- 已有资产：Obsidian笔记库、GitHub仓库（ai-ecommerce-toolkit）、腾讯文档
- 能力边界：不能安装代码环境，只能用手机App和网页工具
