# 平台AI需求挖掘实战手册

## 为什么用平台内置AI？

平台内置AI直接"长"在平台数据里——能读到我们无法直接抓取的评论、商品详情、流量数据，省去大量手动翻找的时间。

**三个核心优势：**
- **数据穿透力**：直接读取评论区的真实痛点、竞品商品的完整数据和用户画像
- **语境理解力**：理解本平台的"行话"和潜规则，比如闲鱼上的"刀"和"闲置"话术体系
- **即时响应**：不需要导出数据、整理格式、再喂给外部AI，平台内完成闭环

## 闲鱼「鱼卖卖」—— 需求挖掘 & 竞品拆解

鱼卖卖的核心能力是辅助卖货，但反过来也能用来做需求调研。

### 1. 挖掘需求缺口

复制以下模板，替换[关键词]：

```
在闲鱼上搜索了"[关键词]"，请你帮我提炼：
- 买家最常问但没有被满足的3个需求是什么？
- 从评论区的"差评"和"建议"中，找出3个产品改进方向
- 哪些价格区间（0-50 / 50-100 / 100-200）买家最多但卖家最少？
- 用一句话总结这个品类买家的核心痛点
```

**为什么这样问：** 直接让AI从价格、评论、供需三个维度帮你定位空白市场。

### 2. 竞品拆解

```
请分析这个链接[粘贴竞品链接]的详情页：
- 他用了哪3个最能打动买家的卖点？
- 评论区高频词是什么？买家最在意什么？
- 他的定价策略是什么？和同类比优势在哪？
- 如果我要做差异化，应该从哪里切入？
```

**为什么这样问：** 让AI提炼卖点关键词、评论情感、定价逻辑，而不是让你自己逐条翻评论。

### 3. 爆款反向推导

```
在[品类]下，近30天卖得最好的前10个商品，请帮我总结：
- 标题的共同关键词（前5个）
- 描述的共同结构（用了什么模板？）
- 图片的共同特征（多少张？什么风格？）
- 定价的共同规律（什么价位最畅销？）
```

**为什么这样问：** 让AI帮你做"规律总结"而不是"数据罗列"。

## 小红书「点点」—— 内容趋势 & 评论区金矿

小红书的评论区是需求挖掘的天堂，因为用户会直接说出"想要什么"和"讨厌什么"。

### 1. 评论区需求提取（最核心能力）

```
请分析这篇笔记[粘贴链接]的评论区：
- 提取所有"想要"类评论（如"好想要""在哪买""求链接"），按频率排序前5个需求
- 提取所有"吐槽"类评论，归纳出3个核心痛点
- 提取所有"对比"类评论，列出用户最常拿来对比的替代品
- 用一句话总结：这个品类的用户最在意什么？
```

**为什么这样问：** 评论区是免费的"用户调研问卷"，AI帮你做分类和归纳。

### 2. 内容选题方向

```
在[品类]领域，近7天互动量最高的笔记：
- 标题用了什么句式？（列举3个模板）
- 封面图有什么共同特征？
- 评论区最常出现的问题是哪些？（这可以直接作为下一篇选题）
- 哪些话题热度高但内容少？（蓝海选题）
```

**为什么这样问：** 让AI帮你做"选题策划"，而不是自己刷几百篇笔记。

### 3. 对标账号拆解

```
请分析这个博主[粘贴链接]的账号：
- 他的爆款内容有什么共同特征？
- 他的人设定位是什么？用一句话概括
- 他的变现路径是什么？广告/带货/私域？
- 我可以学习的3个点是什么？
- 我可以差异化的3个点是什么？
```

**为什么这样问：** 让AI拆解"人设"和"变现路径"，而不是只看表面数据。

## 抖音「豆包」—— 视频脚本 & 热点捕捉

豆包在抖音生态内有天然优势，可以直接分析视频内容和评论。

### 1. 热点需求捕捉

```
在[品类]领域，近7天：
- 哪些话题的视频播放量排名前10？按主题归类
- 评论区最常出现的3个"求推荐"类型问题是什么？
- 哪些视频的"收藏率"异常高？（收藏高=用户想留着用）
- 有什么新出现的需求词或趋势词？
```

**为什么这样问：** 收藏率高代表"实用价值"，这就是需求信号。

### 2. 竞品视频拆解

```
请分析这个视频[粘贴链接]：
- 前3秒的钩子是什么？为什么能留住人？
- 文案结构是什么？（问题-方案-案例 / 颠覆认知-论证-结论）
- 评论区用户最关注的3个问题？
- 如果我要拍一个同类视频，应该保留什么、改变什么？
```

**为什么这样问：** 让AI拆解"钩子"和"结构"，这是爆款视频的核心。

### 3. 脚本生成

```
根据以下需求，帮我写一个抖音视频脚本：
- 目标人群：[你的目标用户]
- 核心卖点：[你的差异化点]
- 时长：30-60秒
- 风格：真实测评风 / 干货教程风 / 情感共鸣风
- 要求：前3秒有钩子，中间有干货，结尾有引导互动
```

**为什么这样问：** 给AI明确的人设和风格，输出更精准。

## 高效提问的通用原则

| 原则 | 说明 | 示例 |
| --- | --- | --- |
| 角色化 | 给AI一个身份，输出更聚焦 | "你是一个资深闲鱼选品顾问" |
| 数量化 | 明确要几个结果，防止AI敷衍 | "找出前5个""归纳3个" |
| 结构化 | 要求表格/分类输出，而不是散文 | "按痛点/需求/机会分类" |
| 对比化 | 让AI做对比，而不是单点描述 | "和竞品相比，差异化在哪" |
| 追问化 | 第一轮问"是什么"，第二轮问"为什么" | 先问趋势，再问原因，最后问怎么做 |

## 完整工作流示例

以闲鱼"AI绘画"品类为例，三轮提问完成一次完整的需求调研：

**第一轮（广度扫描）：**

在闲鱼"AI绘画"品类，帮我总结：
- 近30天销量前20的商品，按"服务类型"分成几类？
- 每类的平均价格和销量范围？

**第二轮（深度挖掘）：**

其中"AI头像定制"这个细分品类：
- 评论区的差评主要集中在哪3个问题？
- 买家最常问但卖家没回答的问题是什么？

**第三轮（机会判断）：**

综合以上，如果我要做一个差异化的AI绘画服务：
- 应该主打什么卖点？
- 定价多少？
- 描述怎么写？

这样三轮下来，相当于完成了一次免费的用户调研+竞品分析+产品定位。

## 核心心法

平台内置AI的核心价值是把"刷信息"变成"问信息"——你不再需要手动翻几百条评论、对比几十个竞品，而是直接提问，让AI帮你提炼。

这会大大缩短你在这些平台上的信息收集时间，让你把精力集中在"判断"和"执行"上，而不是"浏览"和"整理"上。
