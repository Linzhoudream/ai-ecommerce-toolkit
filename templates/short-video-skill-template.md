# 短视频创作 Skill 模板

## 概述

这是一个可复用的AI辅助短视频创作流程。从需求挖掘到成片合成，六阶段SOP，每次换赛道/换人物时直接套用。

**适用场景**：历史人物×当代困境 跨界短视频（知识型/避坑型）

**预计耗时**：首次3-4小时，熟练后1.5-2小时

**成本**：0元（AI工具免费额度 + 剪映免费版）

---

## 阶段一：需求挖掘

### 目标
确认当前社会热点话题，找到目标人群的真实痛点。

### 操作步骤
1. 确定目标人群（如：电商卖家、中年职场人、AI焦虑人群）
2. 搜索该人群当前最关心的话题（搜"2026年XX人群痛点""XX行业困境"）
3. 记录关键数据（如：仅退款占商家投诉34%、灵活就业2.4亿人）
4. 输出：需求清单（3-5个痛点，按热度排序）

### AI工具
- WebSearch 搜社会热点
- 整理数据为结构化表格

### 人机分工
- AI：搜索、整理数据
- 人：确认哪些痛点最能引起共鸣

---

## 阶段二：对标拆解

### 目标
搜索同类内容，找到差异化空间。

### 操作步骤
1. 搜索"历史人物+职场/创业/避坑"相关账号
2. 搜索目标人物的抖音话题播放量、内容供给量
3. 分析竞品的内容模式（结构、时长、风格）
4. 确认：有没有人做过"历史故事→当代映射→坑→检测→解法"五步结构？
5. 输出：竞品分析表 + 差异化定位

### AI工具
- WebSearch 搜竞品账号
- 分析数据，生成对比表

### 人机分工
- AI：搜索、分析数据
- 人：看竞品视频感受"感觉"，判断差异化方向

---

## 阶段三：选题脚本

### 目标
选定人物，撰写短视频脚本。

### 操作步骤
1. 根据数据选人（优先选"内容供给极低+IP天然匹配"的）
2. 确定脚本结构：前3秒钩子 → 历史故事（15秒）→ 当代映射（15秒）→ 坑（10秒）→ 检测方法（10秒）→ 解法（10秒）→ 互动引导（5秒）
3. 撰写脚本，总时长控制在60-75秒
4. 准备3个标题备选
5. 输出：完整脚本 + 标题备选

### 脚本格式模板
```
### 前3秒钩子
> [反常识/悬念/情绪冲击]

### 正文（60秒）
**历史故事（15秒）**
> [3-5句，讲清楚人物+关键事件+结局]

**当代映射（15秒）**
> [2-3句，用真实数据连接当代困境]

**坑（10秒）**
> [1-2句加粗，直击本质]

**检测方法（10秒）**
> [1-2步，可操作的自检问题]

**解法方向（10秒）**
> [1-2句，给出方向但不替人做决定]

### 结尾互动引导（5秒）
> [评论区提问，引导互动]
```

### AI工具
- AI写脚本初稿
- 提供3个标题备选

### 人机分工
- AI：写脚本草稿
- 人：加入真实语气，自检"我会看完吗？我会行动吗？"

---

## 阶段四：拍摄制作

### 目标
用AI生成画面，在剪映中合成视频。

### 操作步骤

#### 4.1 生成画面
1. 根据脚本拆解5-6个关键画面
2. 用AI生图工具生成（即梦/豆包/通义万相）
3. 每张图审核三个维度：视觉美观度、历史准确度、概念匹配度
4. 不合格的重新生成（调整提示词）
5. 输出：5-6张场景图

#### 提示词公式
```
[风格] + [人物描述] + [场景描述] + [光线氛围] + [构图比例]

示例：
"明代江南富商沈万三，身穿素色深褐色长袍，无龙纹，头戴方巾，站在水榭栏杆旁，远眺运河商船，暖金色夕阳光，写实风格，16:9横构图"
```

#### 4.2 生成字幕
1. 根据脚本时间轴创建SRT字幕文件
2. 时间码规则：每句2-5秒，总时长与脚本匹配
3. 输出：subtitles.srt

#### 4.3 生成配音
1. 推荐：剪映内置「文本朗读」→「解说男声」（免费、中文好）
2. 备选：edge-tts（需要网络）、豆包TTS（150元/年）
3. 语速：1.0x，音量：100%

#### 4.4 剪映合成
1. 导入5张图片，按时间轴排列
2. 每张图添加「缓慢放大」效果（Ken Burns）
3. 添加配音
4. 导入SRT字幕
5. 添加BGM（音量20-25%）
6. 图片间「淡入淡出」转场0.5秒
7. 导出1080p/30fps/MP4
8. 输出：最终视频文件

### AI工具
- 即梦/豆包/通义万相 → 生图
- 剪映 → 配音+合成
- AI → 生成SRT字幕 + 合成指南

### 人机分工
- AI：生成画面、字幕、合成指南
- 人：审核画面、在剪映中操作合成、最终审核成片

---

## 阶段五：发布运营

### 目标
让视频被更多人看到，度过冷启动。

### 操作步骤
1. 从3个备选标题中选1个
2. 添加标签：核心标签（#人物名）+ 泛流量标签（#赛道关键词）
3. 选择发布时间：工作日12:00-13:00或18:00-20:00（目标人群活跃时段）
4. 发布后前30分钟：回复每一条评论
5. 转发到朋友圈/微信群（冷启动）
6. 输出：发布信息表

### 发布信息模板
| 项目 | 内容 |
|------|------|
| 标题 | [最终选择的标题] |
| 标签 | #标签1 #标签2 #标签3 #标签4 #标签5 |
| 发布时间 | [日期] [时段] |
| 冷启动渠道 | 朋友圈/微信群/转发 |

### AI工具
- AI：标题对比、标签推荐、发布时间建议

### 人机分工
- AI：提供建议
- 人：最终选择、实际发布、回复评论

---

## 阶段六：数据复盘

### 目标
根据数据诊断问题，指导下一条迭代。

### 操作步骤
1. 发布后24小时查看数据
2. 对照数据诊断速查表判断问题：

| 症状 | 诊断 | 对策 |
|------|------|------|
| 播放低 + 完播高（>30%） | 内容好，但没人点进来 | 优化封面和标题，改前3秒 |
| 播放高 + 完播低（<15%） | 标题骗点击，内容没留住人 | 重做内容，开头不要夸张 |
| 互动率 < 3% | 没让人产生行动冲动 | 加互动引导，结尾留钩子 |
| 粉丝增长慢 | 内容没有关注理由 | 加"关注我学更多"引导 |

3. 记录经验笔记：哪些做对了、哪些需要改
4. 输出：诊断报告 + 迭代清单 + 下一条选题

### AI工具
- AI：数据诊断、趋势分析、生成迭代清单

### 人机分工
- AI：诊断数据、输出建议
- 人：感受反馈、做迭代决策

## 经验笔记

### 沈万三实战记录
- **AI生图常见问题**：AI容易给古代人物加龙纹（僭越），提示词必须明确写"无龙纹""素色长袍"
- **配音选择**：剪映内置TTS免费且中文效果好，不需要额外工具
- **画面数量**：5张图够用，多了反而拖节奏
- **审核注意**：AI生图可能有安全审核失败，概念隐喻类画面（如"地基裂开"）改成抽象表达（如"积木倒塌"）
- **一鱼两吃**：把整个制作过程记录下来，就是第二条内容（教程向）

### 常见坑
- ⚠️ 不要追求完美画面，短视频拼的是内容不是画质
- ⚠️ 前3秒决定一切，把钩子单独拿出来反复测试
- ⚠️ 历史准确性要检查，但不要过度纠结（短视频不是学术论文）
- ⚠️ AI生图右下角可能有水印，发之前裁剪掉
- ⚠️ 每条视频的评论区引导要具体，不要"大家怎么看"这种泛问题
